# Examples

Only small, synthetic and redistributable examples.

- `modules/EX_DecayExample.bas` — fits the decay model, applies the `REG-1` overlay and scores the test window through `IRRBB_Decay` only, on the synthetic series that the development workbook places on the sheet `DecayExample` (`tools/devbuild/`).
 Each future example will identify its model version, input conventions, expected outputs and how to reproduce them using supported APIs.
