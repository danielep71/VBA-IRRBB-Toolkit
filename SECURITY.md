# Security policy

## Private reports

Do not disclose vulnerabilities in public issues or PRs. Contact the maintainer privately through GitHub's permitted security reporting channels.

## Sensitive data and confidentiality

Never commit real bank account records, counterparties, confidential calibration datasets, authentication tokens, vendor code or proprietary methodology documents. Private repository visibility does not waive client confidentiality, GDPR requirements or contractual restrictions. Use synthetic fixture data.

VBA runs with the user's Excel permissions. Review source and comply with enterprise macro policy before enabling execution. No external network actions, code download or unexpected workbook mutations should be introduced without explicit review.
